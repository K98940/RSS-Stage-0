Тест производительности загрузки аудио файлов

Цель: Проверить, что аудио файлы загружаются только при необходимости, а не все сразу.

Инструкции

  1. Откройте Developer Tools (F12)
  2. Перейдите на вкладку Network
  3. Очистите сетевые запросы (кнопка 🚫)
  4. Нажмите "Загрузить приложение"
  5. Наблюдайте за загрузкой файлов в Network
